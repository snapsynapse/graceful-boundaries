# Citation

Graceful Boundaries is an open specification for communicating operational limits, structured refusals, and constructive guidance to humans and autonomous agents. The preferred citation is the versioned specification:

PAICE.work PBC. (2026). *Graceful Boundaries: Specification for communicating operational limits, structured refusals, and constructive guidance* (Version 1.5.4). https://gracefulboundaries.dev/

The machine-readable metadata for this citation is in the repository root at [CITATION.cff](../CITATION.cff). GitHub's “Cite this repository” action reads that file and uses its `preferred-citation` entry when generating citation formats. The preferred citation points to the immutable [version 1.5.4 specification source](https://github.com/snapsynapse/graceful-boundaries/blob/fc2d2e20cd04056fa1cb18ec394155722bc8310c/spec.md); the canonical project landing page remains https://gracefulboundaries.dev/.

The specification and documentation are licensed CC BY 4.0. Code, examples, and the conformance checker are licensed MIT. The root CFF lists both SPDX licenses because the repository has this file-level split; it doesn't mean each file is available under both licenses. See [LICENSE-SPEC](../LICENSE-SPEC) and [LICENSE](../LICENSE).

No DOI is asserted yet. A single specification DOI record is recommended for future archiving, with each version's exact source revision and release date recorded. The ClawHub audit package is a separate MIT-0 derivative and shouldn't receive a competing DOI unless an explicit relation model identifies it as a derivative artifact. Until then, the canonical website and source repository above are the authoritative locations.

The [Citation File Format schema guide](https://github.com/citation-file-format/citation-file-format/blob/main/schema-guide.md) defines `preferred-citation` and the `standard` reference type. GitHub's [CITATION.cff documentation](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/about-citation-files) documents how GitHub renders preferred citations. Local validation with the official `cffconvert` validator passes; GitHub's rendered “Cite this repository” output remains pending until the file is present on the default branch.
